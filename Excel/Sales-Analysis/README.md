 📊 Superstore Sales Analysis

     Project Overview

This project presents an interactive Excel dashboard built using the Superstore Sales dataset. The dashboard helps analyze sales performance across different categories, customer segments, shipping modes, and time periods.

     Objectives

- Analyze overall sales performance
- Compare sales by category
- Analyze customer segments
- Evaluate shipping methods
- Monitor monthly sales trends
- Identify the Top 10 products by sales

     Dataset

- Dataset: Superstore Sales Dataset
- Format: Excel (.xlsx)
- Rows: 9,800
- Columns: 18


     Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design

     Dashboard Features

- Total Sales KPI
- Total Orders KPI
- Categories KPI
- Sales by Category
- Sales by Segment
- Sales by Ship Mode
- Monthly Sales Trend
- Top 10 Products
